# DSSC v0.3 ES256 收尾工具包

本工具包用于：

1. 将成员2 checkpoint的活跃配置与Credential ID更新为v0.3；
2. 生成ES256的LegalPerson VC-JWT、ServiceOffering VC-JWT和VP-JWT；
3. 生成INV-01至INV-07无效测试材料；
4. 使用公网DID Document完成本地验签；
5. 归档v0.2旧说明，生成v0.3交接文档和哈希表。

## 一、放置方式

将本ZIP直接解压到项目根目录：

`C:\Users\HUAWEI\Desktop\暑假dssc\成员2-Credential集成-v0.3-es256-candidate-20260817`

解压后应看到：

- `scripts\prepare-v03-es256-candidate.py`
- `scripts\build-es256-candidate-jwts.py`
- `scripts\verify-es256-candidate-jwts.py`
- `scripts\finalize-v03-docs.py`

工具包不包含任何额外密钥，只使用项目中已有的A组公开教学Demo JWK。

## 二、运行方式

在项目根目录打开PowerShell。每个代码块一次性整块粘贴，等它运行完再继续。

### 1. 确认位置

```powershell
Get-Location
Test-Path -LiteralPath ".\02-config\demo-config.json"
Test-Path -LiteralPath ".\scripts\prepare-v03-es256-candidate.py"
```

两条 `Test-Path` 都应输出 `True`。

### 2. 确认Python密码库

```powershell
py -c "import cryptography; print(cryptography.__version__)"
```

如果报 `No module named cryptography` ，运行：

```powershell
py -m pip install cryptography
```

然后重新执行版本检查。

### 3. 完成签名前小修正

```powershell
py .\scripts\prepare-v03-es256-candidate.py
```

最后应出现：

`v0.3 ES256 candidate preparation: PASS`

### 4. 重新运行未签名一致性检查

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\check-consistency.ps1
```

最后应出现：

`Overall result: PASS`

### 5. 生成ES256候选包

```powershell
py .\scripts\build-es256-candidate-jwts.py
```

最后应出现：

`ES256 candidate JWT generation: PASS`

### 6. 用公网DID验签

```powershell
py .\scripts\verify-es256-candidate-jwts.py
```

最后应连续出现：

- `Public DID resolution and key match: PASS`
- `ES256 candidate JWT verification: PASS`

### 7. 更新最终文档与哈希

```powershell
py .\scripts\finalize-v03-docs.py
```

最后应出现：

`Member2 local ES256 candidate is ready for packaging and member3 handoff.`

## 四、压缩交付ZIP

先回到项目的上一级目录：

```powershell
$projectRoot = (Get-Location).Path
$projectName = Split-Path -Leaf $projectRoot
$parent = Split-Path -Parent $projectRoot
$zipPath = Join-Path $parent "成员2-Credential集成-v0.3-es256-candidate-20260817.zip"

Compress-Archive `
    -LiteralPath $projectRoot `
    -DestinationPath $zipPath `
    -CompressionLevel Optimal `
    -Force

Get-FileHash -Algorithm SHA256 -LiteralPath $zipPath
Write-Host "交付ZIP：$zipPath" -ForegroundColor Green
```

## 五、边界

- 以上全部PASS后，成员2的本地工作就基本完成了。
- 这仍是ES256 candidate，不是Gaia-X Compliance PASS。
- 成员3需使用 `07-evidence\member2-handoff-summary.md` 调用Compliance API并保存响应。
- 不要删除 `.gitignore`。其中 `*.jwk` 不会忽略以 `.jwk.json` 结尾的A组教学Demo密钥，但会继续防止真实本地秘密被误提交。
- 当前目录不是Git仓库也不影响上述本地步骤。内容全部PASS后，再只处理一个团队GitHub仓库，不需要同时克隆A组仓库。
